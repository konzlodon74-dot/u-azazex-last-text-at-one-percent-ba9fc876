# Last Text at One Percent

A dying phone at one percent battery spends its final charge on one last text
instead of saving itself — a short, punchy goodbye in the phone's own voice,
equal parts devotion, poor judgment, and a parting shot at the charger it
never liked. When run, `main.py` writes that single message to
`/output/entry.txt`.
